# Schindler Motors — правила проекта

- Это отдельный сайт Schindler Motors. Не переносить сюда инвентарь и контакты B&B или Framingham.
- Источник автомобилей: `data/inventory.json`.
- После изменения `index.html` или инвентаря из родительской папки запустить `node .\generate_vehicle_routes.js`, затем `node .\verify_package.js`.
- Сохранять визуальную систему `Memory Lane 1950s`, понятную для мужчин 55+ в США.
- Лид должен быть привязан к конкретной машине; цена показывается открыто.
- Не публиковать и не отключать `demoMode` без подключённой CRM и end-to-end проверки формы.
- После значимых изменений обновить `STATUS.md` этого сайта и общий статус пакета.
